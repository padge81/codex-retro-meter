# Contributing

Bug reports and pull requests are welcome. For a bug report, include the Windows version, Codex version, steps to reproduce and expected behavior. Redact account details, private chat contents and credentials.

Before submitting a change, run:

```powershell
.\build.ps1 -Test
```

For display changes, check the five-hour value at 0%, 100% and unavailable; check different display scales and readable reset labels. For recovery changes, preserve opt-in behavior, the fresh-allowance gate, duplicate protection, manual stops and existing approval requirements.

Keep runtime cache, settings and chat identifiers out of commits. A pull request must describe which behavior changed and how it was verified. Contributions are provided under the repository's MIT licence.
